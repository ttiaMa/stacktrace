# Stacktrace 0.2

A clearer, more compact Stats page for your AI stack journal.

- See global model, harness and period totals, plus distinct days tracked.
- Browse current models and harnesses separately, with continuous usage duration for each tool.
- Explore Stack insights: first recorded date, last rotation change, average elapsed period duration, most-used tools and your first models and harnesses.
- Read concise labels in English, Italian, Spanish, French and German, with a compact responsive layout.
- Hover over a timeline period to see its title and date range.

Durations count inclusive calendar days through today. Overlapping days count once per tool; consecutive periods form a continuous run, while an uncovered day resets it. Future periods do not contribute to elapsed durations.

## Docker

Images support Linux AMD64 and ARM64:

```sh
docker pull ghcr.io/ttiama/stacktrace:0.2
docker compose -f compose.release.yaml up -d
```

Download the attached `compose.release.yaml`, explicitly pinned to `0.2`. For an existing installation, replace the Compose file, run `docker compose -f compose.release.yaml pull`, then recreate the container with the command above. Preserve your own `config/timeline.yaml`; the attached `timeline.yaml` is only a starter for new installations.

Source builds and Coolify continue to use `compose.yaml`. The YAML schema remains `version: 1`; no configuration migration is required.
