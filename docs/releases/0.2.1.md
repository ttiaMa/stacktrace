# Stacktrace 0.2.1

A small stable-deployment patch for Coolify and reverse proxies.

- `compose.release.yaml` now exposes container port `8080` without publishing a host port, matching `compose.yaml`.
- In Coolify, enable **Preserve Repository During Deployment** when deploying `compose.release.yaml`, so `config/timeline.yaml` is available for the existing bind mount. Route your hostname to container port `8080`.
- The `./config/timeline.yaml` read-only bind mount is unchanged. Source Compose, Dockerfile and release workflow are unchanged.

## Upgrade

Download the attached `compose.release.yaml`, pinned to `ghcr.io/ttiama/stacktrace:0.2.1`, and keep your existing `config/timeline.yaml`. The attached `timeline.yaml` is only a starter for new installations.

```sh
docker compose -f compose.release.yaml pull
docker compose -f compose.release.yaml up -d
```

**Networking change:** direct host access is no longer enabled by default. For local access at `http://localhost:8080`, add `ports: ["127.0.0.1:8080:8080"]` to the `stacktrace` service in your local Compose file.

Images support Linux AMD64 and ARM64. The YAML schema remains `version: 1`; no data migration is required.
