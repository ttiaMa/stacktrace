# Stacktrace 0.1

The first release of [ stacktrace ], a self-hosted journal of your AI tools and the work you made with them.

- Explore a multi-year timeline grouped by activity, with overlapping periods and multiple models sharing a harness.
- Give each period a story, tags and a related project link; read everything in the Journal.
- Browse current tools and all-time totals in Stats.
- Match model and harness icons automatically from their names, using bundled Lobe Icons.
- Choose English, Italian, Spanish, French or German with `site.language` in `timeline.yaml`.
- Self-host with one editable YAML file, a read-only API and no database or frontend build.

## Docker

Images support Linux AMD64 and ARM64:

```sh
docker pull ghcr.io/ttiama/stacktrace:0.1
docker compose -f compose.release.yaml up -d
```

Use the attached `compose.release.yaml` and starter `timeline.yaml` (place the latter in `config/timeline.yaml`), or get both from the source archive. Keep your own timeline bind-mounted at `/config/timeline.yaml` across upgrades. `0.1` pins this release; `latest` follows future releases. Set `STACKTRACE_VERSION` in `.env` to choose a different published version.

For source builds and Coolify, `compose.yaml` remains available. The YAML schema is still `version: 1`, independently of application version `0.1`.
